    Import into Poweramp

    Two minutes, no file manager needed.

    1. Copy the preset

      Choose a profile above and press Copy preset, or download the .txt. The format is the common Preamp / Filter text used by AutoEq and Equalizer APO.

    2. Open the parametric equalizer

      In Poweramp go to Equalizer and switch to the Parametric view.

    3. Import

      Open the menu in that view, choose the import option, and paste or pick the file. Shelves arrive as low and high shelf bands.

    4. Check the preamp

      The preset carries a negative preamp so boosted bands cannot clip. Leave it as imported.

    Menu labels vary slightly between Poweramp builds. The same text also imports into other apps that read AutoEq text, including RootlessJamesDSP.

    How the curves are made

    The data

    Raw responses for the KZ EDX Pro on an IEC 711 coupler and a B&K 5128 fixture, plus the Redmi 12 speaker. All three are normalised to 0 dB at 1 kHz.

    The prediction

    Each filter is evaluated as a 48 kHz biquad, summed, and added to the raw response. The preamp is excluded from the curve and shown separately.

    The limits

    This is a prediction, not a re-measurement. Ear shape, seal and tips move real results by several dB, especially above 4 kHz. The 5128 data has only 42 points, so its curve is coarser.
